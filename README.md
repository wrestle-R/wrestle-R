### A little about me

I build things for the web, my Linux desktop, and whatever else I get curious about. Some turn into proper projects, some give me something to write about.

### What I'm working on

I've gotten really into widgets lately. A lot of what I'm building now lives on my phone's home screen or my Linux desktop.

- [Pingora](https://github.com/wrestle-R/Pingora) connects my Android phone and Linux laptop. Notifications, clipboard, files and home screen widgets.
- [Task-tick](https://github.com/wrestle-R/Task-tick) puts my todos and watchlist in Android widgets, with offline lists and sync. [Try it](https://task-tick-beige.vercel.app/app).
- [Widgets](https://github.com/wrestle-R/widgets) is where I'm making more of them. App Unlocks has five designs for counting phone unlocks. [Try the resizable previews](https://widgets-gules-nu.vercel.app/).
- [LogIt](https://github.com/wrestle-R/LogIt) is a tracker with widgets, inspired by BigRom's LogIt.

<details>
<summary>The tools I'm building around all of this</summary>

- [MultiCodex](https://github.com/wrestle-R/multi-codex) manages Codex accounts across the desktop app, VS Code and CLI.
- [Vathavaran / Varte](https://github.com/wrestle-R/Vathavaran-Variables) keeps encrypted environment files across terminal, web and mobile.
- [ArchJet](https://github.com/wrestle-R/ArchJet) is a local printer workspace for Arch Linux and Hyprland.
- [The Mbappe Special](https://github.com/wrestle-R/Mbappe-Special) is the collection of agent skills I use and customise for how I work.

</details>
